# Cature 빌드 플레이북 — 예준 (Codex)

> 소유: **미니게임(카드 뒤집기 → 여유 시 가위바위보) + 온보딩/Auth.** 도구: **Codex.**
> **시작 조건:** 승아가 `v0-contracts`(G1) 태그한 뒤. 그 전엔 S0 준비만.
> **철칙:** `MinigameFeature`, `OnboardingFeature` 두 패키지 밖은 절대 건드리지 않는다. Core/Services/다른 Feature 수정 금지 — 필요하면 승아에게 계약 요청. Codex는 **각 패키지 디렉터리에서 실행**.

---

## S0 — 펜스 세팅 + mock/토큰 컴파일

**Codex 프롬프트(복붙 · MinigameFeature 폴더에서 실행):**
```
지금 위치는 Packages/MinigameFeature. 이 패키지 안에서만 작업한다.
이 폴더에 AGENTS.md를 만들어 규칙을 적어라:
- 작업 범위: 이 패키지 내부 파일만. Core/Services/다른 Feature/App 수정 금지.
- 데이터는 CorePackage의 CollectionRepository 프로토콜로만 접근(수집 종·usdz·썸네일 읽기). 지금은 CorePackage/Mocks 사용.
- 스타일은 DesignTokens만(하드코딩 금지).
- 완료 전 mock 주입으로 컴파일·프리뷰 확인.
그다음 MinigameFeature.RootView(빈 화면 + "기능" 라벨)를 만들고 Mock 프리뷰가 뜨는지 확인해라.
```
> OnboardingFeature도 `Packages/OnboardingFeature/AGENTS.md`를 동일 규칙(범위만 Onboarding)으로 만든다.
**점검:** 두 패키지 mock+토큰 컴파일·프리뷰.
**커밋:** `chore(game,onboarding): package AGENTS.md + empty root views`

## S1 — 온보딩 · 권한 · Auth

**Codex 프롬프트(OnboardingFeature 폴더):**
```
Packages/OnboardingFeature 안에서만 작업.
온보딩 3~4스텝 슬라이드를 DesignTokens 기반으로 구현:
1) 주변의 생물을 발견해요  2) 이 생명을 알아봐요  3) 필요한 것/방해를 알게 돼요  4) 도감·지도에 수집하고 체험해요.
마지막에 시작 CTA. 진행 중 카메라·위치 권한 안내 카피(문구만; 실제 권한 요청은 승아 서비스가 담당).
Auth(최소): 닉네임·아이디(내부 유니크 형식검증) 입력 → ProfileRepository(mock) 저장.
OnboardingFeature.RootView로 노출. 이 패키지 밖 수정 금지.
```
**점검:** 슬라이드·닉/아이디 저장(mock).
**커밋:** `feat(onboarding): 4-step + auth`

## S2 — 미니게임 프레임

**Codex 프롬프트(MinigameFeature 폴더):**
```
Packages/MinigameFeature 안에서만 작업.
기능 탭 진입 화면(게임 허브)을 구현:
- 게임 선택 카드: '카드 뒤집기'(활성), '가위바위보'(준비중 자리표시).
- 상단에 간단 안내. DesignTokens 사용.
CollectionRepository(mock)에서 수집 종 목록을 읽어와, 게임에 쓸 카드/캐릭터 소스로 준비.
MinigameFeature.RootView로 노출. 이 패키지 밖 수정 금지.
```
**점검:** 허브에서 게임 선택 진입.
**커밋:** `feat(game): hub + game selection`

## S3 — 카드 뒤집기 (MVP 주력)

**Codex 프롬프트(MinigameFeature 폴더):**
```
Packages/MinigameFeature 안에서만 작업.
'카드 뒤집기'(메모리 매칭) 게임을 구현:
- 수집한 종(CollectionRepository mock)의 썸네일로 짝 카드 덱 구성(예: 6쌍=12장). 수집 종이 적으면 있는 만큼.
- 규칙: 두 장 뒤집어 짝이면 유지, 아니면 다시 덮기. 전부 맞추면 완료(간단한 완료 연출·소요 시간/뒤집기 수).
- 상태는 이 패키지 내부에서 관리(코어 오염 금지). DesignTokens로 카드/보드 스타일.
접근성: 카드 최소 터치 영역 확보.
```
**점검:** 매칭·완료 동작. 수집 종 0~적을 때 폴백.
**커밋:** `feat(game): card-flip matching`

## S4 — 가위바위보 (여유 시)

**Codex 프롬프트(MinigameFeature 폴더):**

```
'가위바위보'를 구현: 수집한 종 캐릭터(썸네일/usdz 미리보기) 하나를 상대로,

상태는 패키지 내부. DesignTokens 사용. 이 패키지 밖 수정 금지.
```
**점검:** 판정·결과 동작.
**커밋:** `feat(game): rock-paper-scissors`
