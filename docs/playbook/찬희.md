# Cature 빌드 플레이북 — 찬희 (Codex)

> 소유: **도감(마이) + 홈(지도).** 도구: **Codex.**
> **시작 조건:** 승아가 `v0-contracts`(G1) 태그한 뒤. 그 전엔 S0 준비만.
> **철칙:** `DexFeature`, `HomeFeature` 두 패키지 밖은 절대 건드리지 않는다. Core/Services/다른 Feature 수정 금지 — 필요하면 승아에게 계약 요청. Codex는 **각 패키지 디렉터리에서 실행**(그 폴더 `AGENTS.md`가 최우선 적용).

---

## S0 — 펜스 세팅 + mock/토큰 컴파일

**목적:** 내 패키지에 가드레일을 심고, mock 위에서 빈 화면이 도는지 확인.

**Codex 프롬프트(복붙 · DexFeature 폴더에서 실행):**
```
지금 위치는 Packages/DexFeature. 이 패키지 안에서만 작업한다.
이 폴더에 AGENTS.md를 만들어 다음 규칙을 적어라:
- 작업 범위: 이 패키지(DexFeature) 내부 파일만. Core/Services/다른 Feature/App은 절대 수정 금지.
- 데이터는 CorePackage의 프로토콜(CollectionRepository, SpeciesRepository)로만 접근. 실구현은 통합 때 주입된다 — 지금은 CorePackage/Mocks 사용.
- 색·폰트·간격·컴포넌트는 DesignTokens만 사용(하드코딩 금지).
- 완료 전 이 패키지가 mock 주입으로 컴파일·프리뷰되는지 확인.
그다음 DexFeature.RootView(빈 화면 + "도감" 라벨)를 만들고 Mock으로 SwiftUI 프리뷰가 뜨는지 확인해라.
```
> HomeFeature도 동일하게 `Packages/HomeFeature/AGENTS.md`를 만들어 둔다(범위만 HomeFeature로).
**점검:** 두 패키지가 mock+토큰으로 컴파일·프리뷰.
**커밋:** `chore(dex,home): package AGENTS.md + empty root views`

## S1 — 도감 그리드 · 달성률

**Codex 프롬프트(DexFeature 폴더):**
```
Packages/DexFeature 안에서만 작업.
마이(도감) 화면을 DesignTokens 기반으로 구현:
- 상단: 프로필(이미지/닉/@아이디) — ProfileRepository(mock)에서 읽기.
- 도감 그리드: CollectionRepository(mock)의 수집 종 = 컬러 썸네일, 미수집 = 실루엣.
- 상단 또는 헤더에 달성률(발견 종수/전체 종수) 표시.
데이터는 프로토콜로만. DesignTokens.CardStyle 등 사용. 이 패키지 밖 수정 금지.
```
**점검:** mock 데이터로 그리드·달성률 렌더. 스샷 확인.
**커밋:** `feat(dex): collection grid + completion rate`

## S2 — 종 상세

**Codex 프롬프트(DexFeature 폴더):**
```
Packages/DexFeature 안에서만 작업.
도감 그리드에서 종을 탭하면 종 상세 화면으로:
- 종 소개 + usdz 미리보기 자리(플레이스홀더 뷰) + 발견 지역.
- 공존 카드 재열람: 필요한 조건 / 사람이 방해할 수 있는 행동 2블록(CoexistCard, mock).
- 발견 기록: 촬영 N회, 마지막 발견 시각/위치(Sighting/CollectionEntry, mock).
프로토콜로만 접근. 토큰만 사용.
```
**점검:** 상세 진입·재열람 동작(mock).
**커밋:** `feat(dex): species detail`

## S3 — 홈 (지도)

**Codex 프롬프트(HomeFeature 폴더에서 실행):**
```
지금 위치는 Packages/HomeFeature. 이 패키지 안에서만 작업.
홈 지도 화면을 구현:
- MapKit(Map)으로 지도 표시. 수집한 생물을 발견 위치에 마커로(SightingRepository/CollectionRepository, mock).
  마커는 종 썸네일 + 라벨 칩.
- 하단 가로 개체 카드: 썸네일·카테고리·이름·거리/상태(LocationService mock로 현재 위치, 거리 계산).
- DesignTokens 사용(라이트 지도 톤). 좌표 없는 기록은 목록으로 폴백.
데이터는 CorePackage 프로토콜로만. HomeFeature 밖 수정 금지.
HomeFeature.RootView로 노출(App 셸이 나중에 꽂음).
```
**점검:** mock 좌표로 마커·카드 렌더.
**커밋:** `feat(home): map + creature markers + card`

## S4 — 폴리시 + 실구현 연결 (통합 때)

**Codex 프롬프트:**
```
통합 브랜치에서, DexFeature/HomeFeature가 승아의 실구현(Data/Services) 주입으로 동작하는지 확인.
깨지면 원인이 (a) 내 패키지 내부면 고치고, (b) 계약/실구현이면 승아에게 이슈로 넘긴다(직접 수정 금지).
빈 상태(수집 0건), 긴 이름, 미수집 실루엣 등 엣지 케이스 폴리시. 시안과 간격/색/폰트 비교.
```
**점검:** 실데이터로 도감·홈 동작 + 시안 일치.
**커밋:** `polish(dex,home): real data + edge cases`
