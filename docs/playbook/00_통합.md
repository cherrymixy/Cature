## 2. 멤버별 STEP 인덱스

**승아 (Claude Code) — 초기 세팅 + 발견 + AR**
- S0 스캐폴드(SwiftUI·SPM·CLAUDE.md·루트 AGENTS.md)
- S1 Core: 모델·프로토콜·**Mock**
- S2 DesignTokens
- S3 앱 셸·탭·카메라 FAB·라우팅(placeholder) → **G1**
- S4 로컬 저장(Repository 구현)
- S5 LLM 서비스(식별+공존카드)
- S6 위치·카메라 캡처
- S7 발견 플로우(카메라·분석·공존카드·수집연출)
- S8 AR 체험(RealityKit usdz) → **G2 확정**
- S9 통합·골든패스 → **G3**

**찬희 (Codex) — 도감 + 미니게임** *(G1 후 시작)*
- S0 패키지 AGENTS.md + mock/토큰 컴파일
- S1 도감(마이) 그리드·달성률
- S2 종 상세(공존카드 재열람·발견기록·위치)
- S3 미니게임 허브(기능 탭·게임 선택)
- S4 카드 뒤집기(수집 종 짝 맞추기)
- S5 (여유) 가위바위보
- S6 폴리시 + 실구현 연결

**예준 (Codex) — 홈 + 온보딩** *(G1 후 시작)*
- S0 패키지 AGENTS.md + mock/토큰 컴파일
- S1 온보딩(3~4스텝)·권한·Auth
- S2 홈(지도·마커·개체 카드)
- S3 폴리시 + 연결

## 3. 통합 순서 (PHASE 3)

1. 승아 `DataPackage`·`ServicesPackage` 실구현 완료 → 각 Feature의 주입을 **Mock → 실구현**으로 교체.
2. `App` 셸에 각 Feature 루트뷰 배선(탭: 홈=예준, 기능=찬희 미니게임, 마이=찬희 도감 / 카메라 FAB=승아).
3. **골든패스 한 바퀴** 수동 + 통합테스트:
   온보딩 → 홈(지도) → 카메라 발견 → 촬영 → 분석 → 공존카드 → 저장 → 수집연출 → 도감/지도 반영 → 체험(AR) → 미니게임 진입.
4. 화면 폴리시·AR/획득 연출.
